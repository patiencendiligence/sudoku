# Quick Notes (Sudoku Game)

A minimal, distraction-free Sudoku game built as a browser extension. The UI is intentionally simple — no ads, no popups, just a clean puzzle interface disguised as a lightweight notes tool.

## Features
- Level 1–10 difficulty system (gets harder as levels increase)
- Automatic user nickname generation (Korean/English depending on region)
  - Korean: "빨간고양이", "파란토끼", etc.
  - English: "RedCat", "BlueFox", etc.
- Rank emoticons by level
  - 🐹 Level 1: Hamster
  - 🐕 Level 3: Puppy
  - 🦜 Level 5: Parrot
  - 🐬 Level 7: Dolphin
  - ⭐ Level 9: Star
  - 👑 Level 10: Crown (highest level!)
- Progress automatically saved to local storage

## How to Play
1. Click the extension icon
2. Click "Start Game"
3. Click a blank cell and enter a number from 1–9
4. Keyboard or number pad supported
5. Level up on completion!

## Tech Stack
- React 18
- TypeScript
- Vite
- Chrome Extension Manifest V3

# Quick Notes (스도쿠 게임)

가볍고 방해 요소 없는 스도쿠 게임 브라우저 확장 프로그램입니다. 광고나 팝업 없이, 간단한 메모 도구처럼 보이는 미니멀한 UI로 만들었습니다.

## 기능
- 레벨 1~10 난이도 시스템 (레벨이 올라갈수록 어려워짐)
- 사용자 닉네임 자동 생성 (지역에 따라 한글/영문)
  - 한국어 환경: "빨간고양이", "파란토끼" 등
- 레벨별 계급 이모티콘
  - 🐹 레벨 1: 햄스터
  - 🐕 레벨 3: 강아지
  - 🦜 레벨 5: 앵무새
  - 🐬 레벨 7: 돌고래
  - ⭐ 레벨 9: 별
  - 👑 레벨 10: 왕관 (최고 레벨!)
- 로컬스토리지에 진행상황 자동 저장

## 플레이 방법
1. 확장프로그램 아이콘 클릭
2. "게임 시작" 버튼 클릭
3. 빈 칸을 클릭하고 1-9 숫자 입력
4. 키보드 또는 숫자 패드 사용 가능
5. 완료하면 레벨업!

## 기술 스택
- React 18
- TypeScript
- Vite
- Chrome Extension Manifest V3
